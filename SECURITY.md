# Security policy

Report a suspected vulnerability in any Ventryn LLC repository privately to
[support@ventryn.com](mailto:support@ventryn.com).

Do not open a public issue, pull request, or discussion containing exploit details, credentials,
access tokens, personal data, or customer data. Include only the minimum information needed to
reproduce the issue safely, and say which repository and revision it affects.

The default branch is the only supported code line unless a repository states otherwise.

Individual repositories may publish their own `.github/SECURITY.md` when they need to narrow the
supported scope or add product-specific reporting guidance. Where a repository does not, this policy
applies.
